# English 5000 V6.4.0｜常用英文 5000 字

[![自動測試](https://github.com/chienan822454/Learning-English/actions/workflows/test.yml/badge.svg)](https://github.com/chienan822454/Learning-English/actions/workflows/test.yml)

手機優先、可離線的英文學習 Web App（GitHub Pages 靜態網站），給資料中心 CE 技術員練習工作英文和常用英文。
網址：https://chienan822454.github.io/Learning-English/ （用手機開啟後「加入主畫面」，之後沒有網路也能用）

## 功能一覽
- **今日學習**：一鍵「▶ 開始今天的學習」（複習單字 → 學新單字 → 句子跟讀 → CE 情境題，約 15 分鐘）；「⚙️ 調整今日學習」可以加片語、句型、無線電用語、Role Play、意思回想，或用中翻英練句子；📅 每週摘要。
- **單字**：5000 個常用原形（分 5 冊）＋詞形、CE 專業字與縮寫 354 個、職場英文 738 個（含多益 1,247 字章節）；單字卡、複習排程（最長 240 天）、🧠 意思回想、IPA／KK 音標。
- **句子**：精選、單字例句、片語例句、CE 情境對話、📻 無線電用語、多益長例句、🧩 句型替換（24 個句型）；🎤 跟讀評分與逐字回饋、🎙 錄音、🀄 中翻英、點字查意思。
- **情境對話與 Role Play**：70 段 CE 情境對話（含 10 段 EOP 演練），四種難度，依分數安排複習。
- **測驗**：單字、片語（含聽寫）、句子、聽力、對話填空、CE 情境題、無線電代號、發音辨別、📕 錯題本、📈 多益程度估計（非官方）。
- **其他**：深色模式、字體大小、離線使用、每日自動備份（保留 14 天）、匯出／匯入備份。

## 資料存在哪裡
- 學習紀錄、設定和每日自動備份都存在手機的瀏覽器裡（本機空間＋瀏覽器資料庫），**不會上傳到雲端**；App 的程式和字庫從 GitHub Pages 下載後存在手機裡。
- 🎤 語音辨識由手機瀏覽器處理（Android 的 Chrome 會送到 Google 辨識，iPhone 由 Apple 處理）；App 不保存聲音。🎙 錄音只暫存在手機記憶體，重錄或離開就清除。
- 換手機、清除瀏覽器資料或刪除主畫面的 App，紀錄就會不見：請定期在「統計 › 資料備份與還原」按「💾 匯出」或「📤 分享」，存到 OneDrive。

## 版本號規則
- 第一碼（例如 V6）：大改版——整體重新設計、資料格式大改、舊備份需要轉換。
- 第二碼（例如 V6.1）：新功能或新內容。
- 第三碼（例如 V6.1.1）：修正、小調整。
- 每次上傳都會改版本號；畫面標題、「統計 › 版本資訊」、離線快取名稱同步。

## V6.4 更新內容（V6.4.0）
- **🎭 Role Play 沒念到的字放進錯題本**：為了避免把語音辨識的錯誤當成你的錯，只收比較確定的情況——不是「自由回答」難度、這次相似度 50% 以上、只收比較進階的字（CE 專業字、職場英文、常用排名 900 以後；不收常用字、數字、設備編號和縮寫），一次最多 3 個。第一次沒念到先「觀察」，14 天內再沒念到一次才放進錯題本，出處是那一句（可以「🧩 放回原句」重考）；之後念到了就移除。不會改變單字的學習狀態。
- **更快**：今日頁、統計頁的到期數量只看排程表；統計頁的各冊數量掃一遍字表就算完，內容沒變時不重畫；測驗出題的選項用索引排除（結果和原本完全相同）；放回原句、對話填空的比對規則只建一次。
- 字庫沒有變動：更新時手機只下載程式檔。學習紀錄多一個欄位（Role Play 觀察中的字 rpMiss），舊的備份檔照樣可以匯入。
- 新增自動測試 p37。

## 檔案說明
- **App**：`index.html`、`app.js`（依功能分 13 段：版本與工具、學習紀錄與儲存、語音與錄音、句子頁、單字頁、測驗與錯題本、情境對話與 Role Play、今日學習、統計與備份、點字查詢、無線電與發音、句型與意思回想、啟動）、`styles.css`、`sw.js`（離線快取）、`manifest.webmanifest`、App 圖示。
- **字庫**：`data.js`（開啟時需要）、`data-ex.js`（單字例句）、`data-ex2.js`（多益長例句）、`data-more.js`（CE 情境題、發音辨別、點字查詢的人名地名與補充字）、`data-toeic.js`（多益程度估計的題目）、`data-v4.js`（V4 字表，只有很舊的學習紀錄要轉換時才載入）；開啟後依序在背景下載。大的資料用 `JSON.parse('…')` 格式（解析比較快）；`data.js` 的 `KWPRE` 是事先算好的句子關鍵字。字庫改了以後要用工具 `data_build.js` 重新產生（自動測試會檢查）。
- **匯出檔（可用 Excel 開啟）**：`vocabulary_all.csv`、`base_words_5000.csv`、`ce_terms.csv`、`workplace_words.csv`、`toeic_words.csv`、`phrases.csv`、`dialogs.csv`、`dialog_key_phrases.csv`、`situation_quiz.csv`、`lookup_extra.csv`、`sentence_patterns.csv`。
- **本版明細**：`V6.4_change_list.csv`（變更清單）、`V6.4_validation_report.md`（測試結果）。本版沒有新增學習內容。
- **自動測試**：`tests/`（`runall.sh` 跑全部；GitHub 上依 `shards.txt` 分 4 組同時跑；每個測試的內容見 `tests/README.md`）。

- Oxford 3000、Longman Communication 3000：只用來比對有沒有漏掉常用字，沒有使用清單內容；App 的中文、音標與例句都是另外撰寫。
