# English 5000 自動測試

每次上傳到 GitHub 的 main，GitHub 會自動跑這裡的全部測試（設定在 `.github/workflows/test.yml`）。
結果顯示在提交紀錄旁：✅ 全部通過、❌ 有測試失敗。點進去（Actions 頁面）可看每一項結果，也可下載 `test-results`。

## 在自己的電腦執行
```bash
cd tests
npm install                       # 安裝 playwright
npx playwright install chromium   # 下載測試用瀏覽器
# 準備舊版本（升版測試用）
mkdir -p old prev
unzip -q fixtures/old_V5.15.zip -d old          # V5.15
unzip -q fixtures/prev_V5.16.20.zip -d prev     # V5.16.20
# 把網站檔案複製到另一個資料夾再測（不要直接用專案根目錄）
mkdir -p /tmp/site && cp ../index.html ../app.js ../data.js ../data-ex.js ../styles.css ../sw.js ../manifest.webmanifest /tmp/site/
bash runall.sh /tmp/site V5.31.1 english-5000-v5-31-1
```

## 改版時的固定規則
1. 每次上傳都改版本號（第一碼大改版、第二碼新功能、第三碼修正），同步：`index.html` 標題、`app.js` 的 `APP_VERSION`、`sw.js` 的快取名稱 `C`。
2. **字庫有任何變動時**（`data.js` 或 `data-ex.js`），`sw.js` 的 `DATA_FILES` 要改成該檔案 SHA-1 的前 12 碼（`p9_test.js` 會檢查，不一致會失敗）。
3. 測試數量或內容數量（對話段數、情境題數）改變時，同步更新相關測試。
