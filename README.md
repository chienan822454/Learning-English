手機優先、可離線的英文學習 Web App（GitHub Pages 靜態網站）。

## 版本號規則（V5.17.0 起）
- 第一碼（例如 V6）：大改版——整體重新設計、資料格式大改、舊備份需要轉換。
- 第二碼（例如 V5.17）：新功能或明顯的改變。
- 第三碼（例如 V5.17.1）：修正、小調整。
- 每次上傳都會改版本號；畫面標題、「統計 › 版本資訊」、離線快取名稱同步。
- **GitHub 只保留最新版本**（V5.32.0 起）：每次上傳前先清除 GitHub 上的舊檔案和舊版本紀錄，只放最新版本；舊版本的明細檔（變更清單、驗證報告）保存在每一版的完整壓縮檔裡。

## V5.32 更新內容（V5.32.0）
- **常用縮寫 +15**：CE 專業字 +7（AC、DC、kV、CT、RH、CHW、SOC，共 354 個）、職場英文 +8（HR、CEO、ID、PDF、USB、GPS、AI、MRT，共 738 個），都有音標、中文和例句。
- **點字查詢更完整**：人名（Kevin）、中文姓氏（Chen → 陳）、地名（Taipei → 台北、New York → 紐約）會標出類別；單字表沒有的 139 個字（flickering → flicker 閃爍）有補充說明；序數（tenth 第十）、字母代號（B，無線電念 Bravo）、設備編號（FM-4410）也有說明。全部句子約 7.4 萬個英文字，點了都查得到。
- **句子的「③ 關鍵字」**：原本沒有關鍵字的 323 句對話和 30 句無線電句子，自動補上句子裡較進階的字或無線電用語（Say again、Copy…）；現在對話句 816／840、無線電句 29／30 有關鍵字（其餘是「Sure, here you go.」這類很短的句子）。
- **多益長例句分開下載**：1,247 句多益長例句移到 data-ex2.js，單字例句檔從 827 KB 降到 580 KB；開啟後先有單字例句，長例句之後再補上（選「📖 多益長例句」時立即下載），訊號差時比較快能用。
- **今日學習可以自訂**：「⚙️ 調整今日學習」可以選複習、新字數量、片語、句子跟讀、📻 無線電用語、CE 情境題、🎭 Role Play，並顯示預估時間；沒有調整時和原本一樣。**每週摘要**：統計頁「📅 每週摘要」和今日頁「最近 7 天」，比較最近 7 天和前 7 天的學習天數、新字、複習、跟讀、測驗正確率、Role Play。
- **🎤 逐字回饋**：句子頁和 Role Play 用 🎤 念完後，每個字標出念對（綠）或沒念到（紅），點紅字可以聽發音（再點一次慢速），也列出另外聽到的字；顏色和分數的算法一致。
- **片語聽寫（拼字）**：片語測驗可以選「聽寫（拼字）」：聽片語、看中文提示、打出片語，標出錯的字母和字；答錯的會進錯題本「片語聽寫」，綜合測驗也會出聽寫題。
- **儲存空間與備份提醒**：統計頁顯示學習紀錄、每日自動備份等用掉的空間（超過 80% 會提醒）；記錄上次備份的時間，超過 14 天沒備份時今日頁會提醒（可以「稍後提醒」）；匯入舊備份不會被當成新的備份。
- **Role Play 複習排程**：Role Play 結束後依平均相似度安排下次複習（低於 70 隔天、70–84 三天後、85 以上間隔加倍，最長 60 天）；今日頁顯示「🎭 Role Play 待複習」，對話清單標出「待複習」或下次日期。
- **GitHub 只保留最新版本**：上傳前先清除 GitHub 上的舊檔案和舊版本紀錄，只放最新版本。
- 新增自動測試 p25（21 項）、p26（47 項）、p27（52 項）。字庫有更新：手機會重新下載一次字庫。
- 新內容（縮寫、人名地名、補充字）由 Copilot 撰寫並檢查，另存校對表。
